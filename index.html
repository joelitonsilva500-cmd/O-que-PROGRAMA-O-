APRENDA A PROGRAMAR

O QUE É PROGRAMAÇÃO?

Introdução

Programação é o processo de criar instruções para que um computador, celular ou outro dispositivo consiga realizar determinadas tarefas. Essas instruções são escritas usando linguagens de programação, como Java, JavaScript, Python, C++ e muitas outras.

Tipos de Linguagem de Programação:

•Java
•JavaScript
•Python
•TypeScript
•C++
•Dentre vários outros.

Um programador utiliza a programação para desenvolver sites, aplicativos, jogos, sistemas, programas e ferramentas digitais. Para isso, ele precisa pensar em uma sequência de passos que o computador consiga entender e executar.

ONDE A PROGRAMAÇÃO É UTILIZADA?

A programação é usada por exemplo, em um jogo, a programação pode determinar o que acontece quando o jogador aperta uma tecla, como o personagem se movimenta, como os inimigos agem e como o sistema calcula a pontuação. Saiba mais

A programação também envolve lógica, criatividade e resolução de problemas. O programador precisa identificar um problema, criar uma solução e transformá-la em comandos que o computador possa executar.
